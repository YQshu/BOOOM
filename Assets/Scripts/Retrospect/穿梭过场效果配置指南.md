# 回溯穿梭过场效果配置指南

## 🎬 效果说明

这个穿梭过场效果会在进入回溯时播放，模拟"穿越时空"的视觉体验：

**动画流程：**
1. **冲入阶段（0-0.3秒）**：画面快速扭曲、色差爆发，模拟冲入时空隧道
2. **稳定阶段（0.3-0.8秒）**：效果逐渐减弱，稳定到正常回溯状态
3. **回溯状态**：保持稳定的复古 CRT 效果
4. **退出**：效果平滑淡出

## 🔧 配置步骤

### 1. 替换控制器脚本

1. **删除旧的控制器**
   - 选中场景中的 `Retro Effect Controller` 物体
   - 在 Inspector 中找到 `RetroTVEffectController` 组件
   - 点击组件右上角的三个点 > `Remove Component`

2. **添加新的控制器**
   - 在同一个物体上点击 `Add Component`
   - 搜索 `RetroTransitionController`
   - 添加组件

### 2. 配置 Volume Profile（重要！）

选中你的 `Retro Effect Volume`，确保 Volume Profile 中的效果**勾选了 Override**：

#### Lens Distortion（镜头扭曲）
```
☑ Intensity (必须勾选！)
   值: -0.12
☑ X Multiplier
   值: 1.0
☑ Y Multiplier
   值: 1.0
```

#### Chromatic Aberration（色差）
```
☑ Intensity (必须勾选！)
   值: 0.35
```

#### Vignette（暗角）
```
☑ Intensity
   值: 0.3
☑ Smoothness
   值: 0.35
☑ Rounded
   值: true
```

#### Film Grain（胶片颗粒）
```
☑ Type
   值: Thin1
☑ Intensity
   值: 0.35
☑ Response
   值: 0.8
```

**⚠️ 关键：** Lens Distortion 和 Chromatic Aberration 的 Intensity 参数**必须勾选 Override**，否则脚本无法动态修改！

### 3. 配置 RetroTransitionController

选中 `Retro Effect Controller` 物体，配置参数：

#### Volume 引用
```
Retro Volume: 拖入你的 "Retro Effect Volume"
```

#### 穿梭过场效果
```
☑ Enable Transition: true (启用过场效果)
Transition Duration: 0.8 (过场总时长，秒)
Transition Distortion Peak: -0.5 (穿梭时的最大扭曲)
Transition Chromatic Peak: 0.8 (穿梭时的最大色差)
Transition Curve: 使用默认的 EaseInOut 曲线
```

#### 稳定回溯效果
```
Target Weight: 0.75 (稳定状态的效果强度)
Fade Out Duration: 0.3 (退出时的淡出时长)
```

#### 正常效果参数（稳定状态）
```
Normal Distortion: -0.12 (稳定状态的扭曲程度)
Normal Chromatic: 0.35 (稳定状态的色差强度)
```

## 📊 参数详解

### Transition Duration（过场时长）
- **0.5秒**：快速，适合频繁切换
- **0.8秒**：标准，平衡视觉效果和节奏（推荐）
- **1.2秒**：慢速，强调仪式感

### Transition Distortion Peak（穿梭扭曲峰值）
- **-0.3**：轻微扭曲，柔和
- **-0.5**：中等扭曲，明显但不过分（推荐）
- **-0.7**：强烈扭曲，戏剧化

### Transition Chromatic Peak（穿梭色差峰值）
- **0.6**：轻微色差
- **0.8**：明显色差（推荐）
- **1.0**：极限色差，RGB 完全分离

### Target Weight（稳定状态强度）
- **0.6**：轻微效果，不影响可玩性
- **0.75**：平衡效果（推荐）
- **0.9**：强烈效果，强调回溯氛围

## 🧪 测试功能

运行游戏后，在 Inspector 中右键点击 `RetroTransitionController` 组件：

- **测试：播放穿梭效果** - 完整播放穿梭动画
- **测试：启用效果（无过场）** - 直接显示稳定状态
- **测试：禁用效果** - 淡出效果

## 🎯 调整建议

### 如果穿梭效果太强烈
1. 降低 `Transition Distortion Peak` 到 -0.3
2. 降低 `Transition Chromatic Peak` 到 0.6
3. 增加 `Transition Duration` 到 1.0（让过渡更平滑）

### 如果穿梭效果不明显
1. 增加 `Transition Distortion Peak` 到 -0.6 或 -0.7
2. 增加 `Transition Chromatic Peak` 到 0.9 或 1.0
3. 减少 `Transition Duration` 到 0.6（让峰值更突出）

### 如果想要更快的节奏
1. 减少 `Transition Duration` 到 0.5
2. 减少 `Fade Out Duration` 到 0.2

### 如果想要更慢的仪式感
1. 增加 `Transition Duration` 到 1.2
2. 增加 `Fade Out Duration` 到 0.5

## 🎬 动画曲线调整（高级）

`Transition Curve` 控制穿梭动画的加速/减速：

### 默认（EaseInOut）
- 开始慢 → 中间快 → 结束慢
- 适合大多数情况

### 自定义曲线建议

**快速冲击型：**
- 开始快速上升，然后缓慢下降
- 在 Inspector 中点击曲线编辑器
- 调整为：起点斜率陡峭，终点斜率平缓

**平滑过渡型：**
- 保持匀速
- 使用线性曲线（Linear）

**弹性效果型：**
- 超过目标值后回弹
- 需要手动调整曲线，让峰值超过 1.0

## 🎮 实际游戏流程

1. **玩家打开线索墙** → 无效果
2. **玩家选择嫌疑人** → 无效果
3. **点击"开始回溯"** → 🎬 **穿梭动画播放**
   - 0.0-0.3秒：画面快速扭曲、色差爆发
   - 0.3-0.8秒：效果逐渐稳定
   - 0.8秒后：保持稳定的回溯效果
4. **回溯进行中** → 保持 CRT 效果
5. **按 ESC 退出** → 效果平滑淡出（0.3秒）
