## 🔍 排查步骤

### 第一步：确认脚本已添加到场景

1. **检查场景中是否有 RetroTransitionController**

   - 选中后在 Inspector 中确认有 `RetroTransitionController` 组件

2. **如果没有，重新添加：**
   - 选中 `Retro Effect Controller` 物体
   - 删除旧的 `RetroTVEffectController` 组件（如果还在）
   - 添加 `RetroTransitionController` 组件

### 第二步：检查 Volume 引用

```
│
```

**如果 Retro Volume 是空的（None）：**

### 第三步：检查 Volume Profile 配置（关键！）

选中你的 Volume 物体（例如 `Retro Effect Volume`），在 Inspector 中：

1. **确认 Profile 不为空**
   ```

   ├─ Profile: [必须有一个 Profile]  ← 不能是 None！
   ```

2. **点击 Profile 查看详情**

   - 或者直接在 Inspector 中展开查看

3. **检查必须勾选的 Override（最关键！）**

   - `Lens Distortion > Intensity` 必须勾选

## 🔧 常见问题解决

### 问题 1：测试功能有效，但实际进入回溯无效

**原因：** 事件订阅时机问题

**解决方案：**
1. 确保 `Retro Effect Controller` 在场景加载时就存在（不是运行时创建的）
2. 确保 `RetroTransitionController` 的 `OnEnable` 在 `RetrospectManager` 之后执行

**临时解决方案：**
在 `RetroTransitionController.cs` 的 `Start` 方法中重新订阅：

```csharp
private void Start()
{
    // 延迟订阅，确保 RetrospectManager 已初始化
    if (RetrospectManager.Instance != null)
    {
        RetrospectManager.Instance.OnRetrospectEnter += OnEnterRetrospect;
        RetrospectManager.Instance.OnRetrospectExit += OnExitRetrospect;
        Debug.Log("[RetroTransition] 事件订阅成功");
    }
    else
    {
        Debug.LogError("[RetroTransition] RetrospectManager.Instance 为空！");
    }
}
```

### 问题 2：效果只有淡入淡出，没有穿梭动画

**原因：** Lens Distortion 或 Chromatic Aberration 的 Intensity 没有勾选 Override

**解决方案：**
1. 选中 Volume 物体
2. 在 Inspector 中找到 Volume Profile
3. 展开 `Lens Distortion`
4. 确保 `Intensity` 左边的复选框 ☑ 已勾选
5. 展开 `Chromatic Aberration`
6. 确保 `Intensity` 左边的复选框 ☑ 已勾选

### 问题 3：效果在编辑器中看不到

**原因：** Game 视图未启用后处理预览

**解决方案：**
1. 点击 Game 视图右上角的设置图标（三个点）
2. 确保 `Post Processing` 已勾选

### 问题 4：黑幕还在显示

**原因：** 场景中的 DarkOverlay 物体仍然激活

**解决方案：**
1. 在 Hierarchy 中搜索 `DarkOverlay` 或 `Dark Overlay`
2. 选中后在 Inspector 中取消勾选（禁用）
3. 或者在 RetrospectManager 的 Inspector 中，将 `Dark Overlay` 字段设置为 None
