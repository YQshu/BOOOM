# 动画回溯系统开发计划

> 目标：三天内完成单嫌疑人完整闭环（选择→进入回溯→时间控制→NPC行为播放→两种线索获取→退出）

---

## 系统架构

```
CharacterSelectManager.SelectCharacter()
        │
        ▼
RetrospectManager.EnterRetrospect(loopId, director)
        │
        ├── TimelineRewindManager（时间控制：播放/暂停/回溯/拖动）
        ├── TimeProgressBar（进度条UI）
        ├── NpcRoomTracker（追踪NPC当前房间）
        ├── PlayerMovementConstraint（限制玩家在NPC所在房间内）
        ├── ClueSignalReceiver（Timeline信号触发线索/对话）
        ├── VisionMaskController（视野遮罩跟随NPC）
        └── InkDialogueManager（对话时暂停Timeline）
```

## 新建脚本（4个）

### 1. `Assets/Scripts/Retrospect/RetrospectManager.cs`

回溯模式总协调器。

- `EnterRetrospect(string loopId, PlayableDirector director)` — 进入回溯
- `ExitRetrospect()` — 退出回溯
- `PauseForDialogue()` — 对话开始时暂停Timeline
- `ResumeFromDialogue()` — 对话结束时恢复Timeline
- `IsInRetrospect` — 状态查询
- 事件：`OnRetrospectEnter` / `OnRetrospectExit`

### 2. `Assets/Scripts/Retrospect/NpcRoomTracker.cs`

追踪Timeline驱动的NPC当前所在RoomZone。

- `BindNpc(Transform npcTransform)` — 绑定追踪目标
- `Unbind()` — 解除绑定
- `CurrentRoomBounds` — 当前房间Collider2D
- 事件：`OnNpcRoomChanged(Collider2D newBounds)`
- 实现：每0.2秒用 `Physics2D.OverlapPoint` 检测NPC位置

### 3. `Assets/Scripts/Retrospect/PlayerMovementConstraint.cs`

将玩家移动限制在指定Collider2D区域内。

- `EnableConstraint(Collider2D bounds)` — 启用约束
- `UpdateBounds(Collider2D newBounds)` — NPC换房间时更新
- `DisableConstraint()` — 禁用约束
- 实现：`LateUpdate` 中用 `ClosestPoint` 将越界玩家拉回

### 4. `Assets/Scripts/Retrospect/ClueSignalReceiver.cs`

接收Timeline Signal，触发线索收集或对话。

- 实现 `INotificationReceiver` 接口
- 配置列表：每个Signal对应 clueId + clueName + 可选inkStory
- 有inkStory时：暂停Timeline → 启动对话 → 对话中通过tag自动收集
- 无inkStory时：直接 `ClueManager.CollectClue()`

需同时创建 `Assets/Scripts/Retrospect/ClueSignalAsset.cs`（继承SignalAsset的空标识）

## Timeline资产结构（每个嫌疑人一个）

```
Timeline: "Suspect_A_Retrospect"
├── [Animation Track] — NPC位置+动画（绑定NPC Animator）
├── [Signal Track] — 线索/对话触发点（绑定ClueSignalReceiver）
├── [Activation Track] — 可选，控制交互物品显隐
└── [Control Track] — 可选，嵌套子Timeline
```

## 线索获取方式

| 类型 | 触发方式 | 实现 |
|------|---------|------|
| 自动线索 | Timeline Signal时间点 | ClueSignalReceiver → ClueManager.CollectClue() |
| 对话线索 | Timeline Signal触发Ink对话 | ClueSignalReceiver → PauseForDialogue → InkDialogueManager（# clue tag） |
| 主动线索 | 玩家E键交互场景物品 | 现有Interactable系统，物品可用Activation Track控制时间段可见性 |

所有线索共用 ClueManager 去重。

## 完整交互流程

1. 玩家打开角色选择界面 → 选择嫌疑人
2. `CharacterSelectManager` → `RetrospectManager.EnterRetrospect()`
3. 绑定各子系统 → 激活回溯HUD → 播放Timeline
4. 回溯进行中：
   - NPC沿Timeline路径移动
   - NpcRoomTracker检测房间变化 → 更新玩家约束区域
   - 玩家在当前房间内自由移动，E键交互物品
   - Signal触发 → 自动线索/对话线索
   - 对话期间Timeline暂停，结束后恢复
   - 玩家可随时：暂停/回溯/拖动进度条
5. 按Esc或点击退出 → `RetrospectManager.ExitRetrospect()`

## 风险与应对

| 风险 | 应对 |
|------|------|
| Timeline回溯时NPC位置不刷新 | 使用 `director.Evaluate()` 强制求值（TimelineRewindManager已在用） |
| OverlapPoint检测不到RoomZone | 确保 Physics2D Settings 中 "Queries Hit Triggers" 开启 |
| 对话期间玩家拖动进度条 | PauseForDialogue时禁用TimeProgressBar.interactable |
| NPC换房间时玩家位置跳变突兀 | 加0.3s屏幕淡入淡出过渡 |
| R键冲突（GameBootstrap vs 倒带） | 回溯模式下禁用GameBootstrap的R键重载 |
